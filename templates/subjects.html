Academic subjects.

How Programming, Data Structures and Communicative English meet in this project.

01IMPLEMENTATION

Programming

Python makes the tracker behave; Flask connects those behaviors to the browser.

WHATPython functions, conditions, loops, Flask routes and SQLite operations.
WHERE USEDapp.py validates requests; database.py reads and writes assignments.
WHYTo turn student input into saved, searchable, editable records.
HOWRoutes call shared functions, parameterized SQL handles data, and templates render the result.
02ORGANIZATION

Data Structures

Three structures solve three different jobs in the working application.

WHATPython lists, a LIFO stack and a heap-based priority queue.
WHERE USEDdata_structures.py orders activity; priority.py uses heapq; app routes process record lists.
WHYLists are practical to process, stacks surface recent actions, and heaps rank urgent work.
HOWReal database records flow into each structure. Completed work stays out of the active heap.
03COMMUNICATION

Communicative English

Technical writing makes task details and system feedback understandable.

WHATClear assignment descriptions, meaningful labels and concise explanations.
WHERE USEDThe assignment form, validation messages, priority reasons and AI suggestions.
WHYGood wording reduces ambiguity when planning work and interpreting a score.
HOWDescriptions capture deliverables; every priority and status is named in plain language.
04SUGGESTION LAYER

AI / LLM

A natural-language nudge adds context to the numeric priority.

WHATA suggestion based on difficulty, remaining days, estimated hours and status.
WHERE USEDai_priority.py provides a local rules mode and optional API call.
WHYA score alone cannot explain how to plan around effort and status.
HOWWithout a configured key, transparent rules run locally; a configured endpoint uses an LLM.
05TIME CALCULATION

Date module

Deadlines become a consistent, recalculated measure of time remaining.

WHATPython's datetime.date and ISO date parsing.
WHERE USEDpriority.py calculates days left from each saved deadline.
WHYUrgency changes over time without storing a stale countdown.
HOWRemaining days = deadline − current date; negative values indicate overdue work.
